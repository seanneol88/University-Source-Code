## 🛠️ How this repository publishes itself

Everything you see is generated from the files in this repo — there is no hand-maintained HTML.

- `scripts/build_site.py` scans the folders, renders every README, writes a syntax-highlighted
  page per source file, and regenerates the project table above (and the README of any folder
  that does not have one).
- `.github/workflows/pages.yml` runs that script on every push to `main`, commits any README
  changes back, and deploys the result to **GitHub Pages**.

```bash
python3 -m pip install markdown   # once
python3 scripts/build_site.py     # writes _site/ locally
python3 -m http.server -d _site 8000
```
